# Changelog

## 1.1.0 — Blog kit updates

- Add `pnpm blog:update` to apply the latest stable kit tag to blogs made from
  this template.
- Preserve posts, uploaded images, Obsidian settings, the dashboard, and the
  personal blog configuration during updates.
- Support a one-time update for older blogs that do not have a kit version yet.

## 1.0.0 — First stable release

Next.js Obsidian Blog Kit is a template for publishing an Obsidian vault as a
fast, static blog.

### Highlights

- **Obsidian-first writing** — Write local Markdown posts, manage them from a
  dashboard, and publish with Git push.
- **Quick setup and deployment** — One setup command configures the blog and
  can connect it to Vercel for production deployment.
- **Rich Markdown** — GitHub-flavored Markdown, syntax highlighting, code copy
  buttons, math, Mermaid diagrams, responsive images, and an image lightbox.
- **Blog essentials** — Post navigation, table of contents, pagination,
  galleries, RSS, sitemap, robots.txt, and Giscus comments.
- **Search-ready metadata** — Open Graph images, JSON-LD, canonical metadata,
  and static generation for strong performance and SEO.
- **Polished reading experience** — Responsive layout with light and dark
  themes.
